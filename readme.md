# Guess Number Bot

Telegram-бот для игры «Угадай число». Игроки пишут числа от 1 до 6, бот кидает
кубики через встроенный Telegram-эмодзи 🎲 и сам считает очки по разным
правилам в зависимости от раунда.

## Правила игры

**Раунд 1** — игроки пишут 1 число.
- Угадал → **+1**

**Раунд 2** — игроки пишут 2 числа через пробел (например `3 4`), порядок важен.
- 2 из 2 в правильном порядке → **+5**
- 2 из 2, но не на своих местах → **+2**
- 1 из 2 угадан → **+1**

**Раунд 3** — игроки пишут 3 числа через пробел, порядок важен.
- 3 из 3 в правильном порядке → **+10**
- 2 из 3 в правильном порядке → **+5**
- 3 из 3, но не на своих местах → **+3**
- 2 из 3, но не на своих местах → **+2**
- 1 из 3 угадан → **+1**

Очки за крутку начисляются по **одному, самому старшему** подходящему
правилу — они не суммируются друг с другом.

Если игрок в рамках одной крутки написал ответ несколько раз — засчитывается
**первый** написанный ответ, остальные игнорируются.

## Как играть

1. `/startgame` — начинает новую сессию, обнуляет очки в этом чате.
2. `/round 1` (или `2`, или `3`) — объявляет раунд и открывает приём ответов.
3. Игроки пишут числа в чат (просто текстом, без команды).
4. `/roll` — бот сам бросает нужное количество кубиков подряд (через
   `send_dice`) и закрывает приём ответов.
5. `/check` — бот сверяет собранные ответы с результатом броска, начисляет
   очки и присылает разбор по каждому игроку. После этого приём ответов для
   следующей крутки в этом раунде открывается автоматически.
6. Шаги 3–5 повторяются столько раз, сколько круток нужно в раунде
   (обычно 10–20).
7. При переходе к следующему раунду — снова `/round 2` или `/round 3`.
8. `/scores` — посмотреть текущую турнирную таблицу в любой момент.
9. `/endgame` — завершить игру и показать финальный зачёт с призовыми местами.

## Команды

| Команда | Описание |
|---|---|
| `/start` | Проверить, что бот на связи ("бот работает") |
| `/help` | Показать список всех команд |
| `/startgame` | Начать новую игровую сессию (очки обнуляются) |
| `/round 1\|2\|3` | Объявить текущий раунд, открыть приём ответов |
| `/roll` | Бросить кубики (количество = номер раунда), закрыть приём ответов |
| `/check` | Сверить ответы с броском, начислить очки, показать разбор |
| `/scores` | Показать текущую турнирную таблицу |
| `/endgame` | Завершить игру, показать финальный зачёт |

## Важные детали реализации

- **Приём ответов открыт** только между `/round`/`/check` и `/roll`. Всё, что
  игроки пишут после `/roll`, но до следующего `/check`, в счёт не идёт —
  это защищает от ситуации, когда кто-то меняет ответ, увидев уже брошенные
  кубики.
- Бот **игнорирует** сообщения, которые не похожи на валидный ответ для
  текущего раунда (не то количество чисел, числа вне диапазона 1–6,
  не числа вообще) — можно спокойно общаться в чате, не мешая игре.
- Если игрок написал что-то похожее на ответ, но не прошедшее валидацию
  (например написал 3 числа в раунде 2), это попадёт в `/check` как
  "не распознано, 0 очков", чтобы было видно, что случилось.
- **Хранение данных — в памяти процесса.** Это значит, что при перезапуске
  бота на Render (например, при передеплое) текущая игра и очки теряются.
  Для формата "провёл игру за вечер — очистил" это ок и осознанный выбор
  ради простоты. Если понадобится переживать рестарты — это отдельная
  доработка (SQLite/файл), скажи, добавлю.

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен_от_BotFather"
python3 bot.py
```

## Деплой на Render

1. Залить проект в свой Git-репозиторий.
2. В Render создать **Background Worker** (не Web Service — бот работает
   через long polling, ему не нужен открытый HTTP-порт).
3. Build command: `pip install -r requirements.txt`
4. Start command: `python3 bot.py`
5. В Settings → Environment добавить переменную `BOT_TOKEN` со значением
   токена от BotFather.
6. Деплой.

## Структура проекта

```
bot.py            — точка входа, все Telegram-хендлеры
game_state.py      — состояние одной игровой сессии (в памяти)
scoring.py          — чистая логика подсчёта очков (без Telegram-зависимостей)
test_scoring.py     — тесты для scoring.py
requirements.txt    — зависимости
```
